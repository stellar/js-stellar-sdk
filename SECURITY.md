# Security Policy

## Supported versions

All security fixes are released on the **Active** release line of `@stellar/stellar-sdk`. **Maintenance** lines receive critical security fixes only. The table of currently supported versions and their support end dates lives in [RELEASE_POLICY.md](./RELEASE_POLICY.md#currently-supported-versions), which is the single source of truth.

## Reporting a vulnerability

The Stellar Development Foundation (SDF) runs a bug bounty program for many of its open source projects, including this SDK. For details on the program and how to report a vulnerability, see the [bug bounty page](https://stellar.org/grants-and-funding/bug-bounty). Please do not open public GitHub issues for security vulnerabilities.
