# Security Policy

## Supported versions

Security fixes are released for the **Active** and **Maintenance** release lines of `@stellar/stellar-sdk`. The table of currently supported versions and their support end dates lives in [RELEASE_POLICY.md](./RELEASE_POLICY.md#currently-supported-versions), which is the single source of truth.

## Reporting a vulnerability

The Stellar Development Foundation (SDF) runs a bug bounty program for many of its open source projects, including this SDK. For details on the program and how to report a vulnerability, see the [bug bounty page](https://stellar.org/grants-and-funding/bug-bounty). Please do not open public GitHub issues for security vulnerabilities.
